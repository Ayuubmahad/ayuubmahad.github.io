# Ayuub Mahad — Portfolio Website

Personal portfolio site for backend and systems-focused software projects.

The site presents three engineering projects:

- **Kassa** — a transaction-safe payments core built around double-entry accounting and idempotent checkout flows.
- **Vakt** — a real-time anomaly-detection engine combining machine learning, rules, safe fallback behavior, and observability.
- **Kompass** — a hybrid search and recommendation engine combining full-text retrieval with semantic search and measurable relevance.

## Purpose

This repository contains the static portfolio site used to explain the engineering decisions, trade-offs, and measured results behind those projects.
